#+title: Supervisor source examples and pending compiler acceptance
#+status: REVIEW

* Source, not IR or runnable host code

These files show the proposed final .star source grammar defined in
[[file:../../../docs/language/SUPERVISOR-GRAMMAR.org][SUPERVISOR-GRAMMAR.org]] and its
[[file:../../../docs/language/supervisor-v1.ebnf][EBNF]]. The actual executable Lisp examples remain one directory above.

Supervisor declarations are NOT accepted by the current parser/compiler.
The .star files are design inputs for a future acceptance suite, not passing
compiler tests. No source-design file is added to the runtime example runner.

| File | Representation | Role |
|------+----------------+------|
| fetcher.star | Existing actor source grammar | Transient child, host binding fetchHandler. |
| normalizer.star | Existing actor source grammar | Permanent child, host binding normalizeHandler. |
| oneShot.star | Existing actor source grammar | Temporary child, host binding oneShotHandler. |
| ingestSupervisor.star | Proposed supervisor source | Flat root with explicit units, fixed backoff, and timed drain. |
| fetchSupervisor.star | Proposed supervisor source | Intermediate supervisor; omitted backoff defaults to none. |
| serviceRoot.star | Proposed supervisor source | Nested rest-for-one root. |
| ingestSupervisor.expected-ir.json | Expected linked IR node projection | Compiler output shape; not a source program or full published manifest. |

Each .star file has exactly one top-level declaration. For the flat example,
link the three actor units with ingestSupervisor and explicitly select
=ingestSupervisor= as root. For the nested example, link the three actor units
with fetchSupervisor and serviceRoot and select =serviceRoot=. These are
alternative activation graphs, not two roots sharing the same live children.
Names are not filenames to auto-load; the host/link request supplies the units.

The handler names are symbolic application bindings. The empty contract lists
avoid inventing unrelated message schemas. These examples contain no Lisp
lambda, package escape, eval, transport, or StarIntel actor-registry definition.

* Expected lowering for the flat example

- =(3 (seconds 10))= becomes maxRestarts 3 and periodMs 10000.
- =(fixed (milliseconds 250))= becomes fixed backoff with delayMs 250.
- =(drain (seconds 5))= becomes drain shutdown with timeoutMs 5000.
- Children resolve to the three actor declarations in the same order.
- The JSON file is an expected node projection, authored alongside the source;
  it was not generated by a compiler that already supports supervisors.

Do not add the supervisor node to the current normalized-IR v2 envelope without
an explicit versioned schema extension. Do not map the proposed timed drain to
the current Lisp driver's max-steps limit.

* Acceptance vectors to implement with the real compiler

| Case | Expected result after grammar implementation |
|------+----------------------------------------------|
| Flat source set above | Valid linked graph; supervisor node equals the expected JSON semantically. |
| Nested source set above | Valid tree; root child order is preserved. |
| Replace one-for-one with one-for-all | Valid target grammar; backend must support it or reject before activation. |
| Permute supervisor option pairs | Equal normalized supervisor node. |
| Omit :backoff / explicitly use none | Equal normalized none backoff with delayMs 0. |
| Use (milliseconds 10000) instead of (seconds 10) | Equal periodMs. |
| Restart count 0 | Valid; first required replacement exhausts intensity. |
| Separate (:strategy ...) (:children ...) clauses | supervisor-shape error; old sketch is not an alias. |
| :strategy :one-for-one | Read/enum validation error; source enum must be bare one-for-one. |
| Duplicate :restart-intensity | supervisor-duplicate-option error. |
| Missing :shutdown | supervisor-missing-option error. |
| :backoff (fixed (milliseconds 0)) | supervisor-duration error; use none. |
| :restart-intensity (3 10) | supervisor-duration error; unit is mandatory. |
| Negative count, float, or overflowed duration | Numeric validation error. |
| :children () | supervisor-child-list error. |
| Child identifier normalzier | supervisor-unknown-child at link, with source span. |
| Same child twice | supervisor-duplicate-child at link. |
| Two reachable parents name normalizer | supervisor-multiple-parents at link. |
| A names B; B names A, or self-reference | supervisor-cycle, including cycle path and spans. |
| Child resolves to a document/external actor | supervisor-child-kind at link. |
| Host root is missing, ambiguous, or an actor | supervisor-root error. |
| Unsupported timed drain/nesting/strategy | supervisor-backend-unsupported before any actor starts. |

No parser, compiler, or runtime acceptance execution is claimed by these vectors.
